# Hire Desi Marketer — Sanity Studio

This is the dedicated, isolated Content Management Studio for **Hire Desi Marketer**.

* **Project ID:** `zabzj0uf`
* **Dataset:** `production`

---

## 🚀 How to Run Locally

1. Open your terminal in this directory:
   ```bash
   cd studio
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the local Studio:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:3333](http://localhost:3333) in your browser!

---

## 🌐 How to Deploy to a Free Live Web Studio (for Your Entire Writing Team)

To give writers a permanent live URL where they can log in and write from anywhere without running code:

1. Inside `studio/`, run:
   ```bash
   npx sanity deploy
   ```
2. Sanity will ask for a studio hostname (e.g., `hire-desi-marketer`).
3. Your live studio will immediately be online at:
   `https://hire-desi-marketer.sanity.studio`
